# Хвоя — заметки для Claude

Electron-приложение для музыки ВК и SoundCloud под Windows. Автор и единственный пользователь кода — Мориус,
общение и весь текст в интерфейсе — по-русски, на «ты».

## Команды

```bash
npm install
node dev/make-fixtures.mjs   # тестовые mp3 для режима без ВК (один раз)
npm run dev:mock             # запуск с поддельным ВК (VK_MOCK=1) — основной способ проверять правки
npm run dev                  # запуск с настоящим ВК (нужен вход)
npm test                     # vitest, 32 файла / 212 тестов — запускать после каждой правки логики
npm run typecheck            # tsc по двум конфигам (node + web)
npm run lint                 # ESLint: ошибок быть не должно, предупреждения — к сведению
npm run check                # lint + typecheck + тесты одной командой
npm run dist                 # установщик локально
```

Переменные для `dev:mock`: `VK_MOCK_LOGIN=1` — стартовать разлогиненным, `SC_DOWN=1` — изобразить
заблокированный SoundCloud.

## Где что лежит

- `src/main/` — главный процесс. `vk/` (API ВК: `client.ts` — подпись официального приложения и повторы,
  `audio.ts` — методы `audio.*`, `models.ts`/`catalog.ts` — разбор ответов, `mock.ts`/`mockServer.ts` — подделка),
  `sc/` (SoundCloud: `soundcloud.ts` — API, ключ `client_id`, потоки; `scAuth.ts` — вход и запись через окно сайта),
  `auth/` (вход в ВК через окно сайта + `TokenKeeper`), `downloads/` (ffmpeg, теги, обложка),
  `system/` (настройки, трей, автообновление, Discord RPC), `ipc/handlers.ts` — регистрация каналов.
- `src/preload/index.ts` — мост: пропускает только каналы из `src/shared/ipc.ts`.
- `src/shared/` — то, что видят оба процесса: `types.ts`, `ipc.ts` (белый список каналов и событий),
  `match.ts` (сопоставление трека ВК ↔ SoundCloud), `updates.ts`.
- `src/renderer/` — окно. `store/` (zustand), `player/` (движок на двух `<audio>` + Web Audio, очередь,
  кроссфейд, перемешивание), `wave/` (отбор Волны: `picker.ts`, `profile.ts`, `tune.ts`), `pages/`, `ui/`,
  `theme/`.
- `docs/superpowers/specs/` — спецификация, `docs/superpowers/plans/` — план работ.

## Как тут принято

- **Весь текст для человека — по-русски, на «ты», без технических кодов.** Ошибки наружу переводятся в
  понятные фразы в `src/main/ipc/handlers.ts` (`friendly()`); «Нет подключения» вместо `ENOTFOUND`.
- **Новый канал IPC = две строки в `src/shared/ipc.ts`:** подпись в `IpcMap` (какие аргументы и что
  возвращает) и имя в `IPC` (белый список моста). Дальше `handle('канал', fn)` в главном процессе и
  `window.api.invoke('канал', …)` в окне берут типы оттуда — руками тип результата писать не нужно.
  Если канал забыли в одном из двух списков, `npm run typecheck` покажет ошибку с его именем.
  Типы, которые ходят по IPC, живут в `src/shared/types.ts` (в том числе `Sc*`, `ForYouBlock`, `LocalPl`);
  главный процесс и окно их только переэкспортируют, второй раз не описывают.
- **Ключи доступа никогда не попадают в журнал.** Пишем через `log()` из `src/main/auth/webSession.ts`,
  он прогоняет текст через `redact()`. Журнал — `%APPDATA%/Хвоя/khvoya.log`.
- **Логика отделена от React и от Electron,** чтобы её можно было протестировать: `*Logic.ts`
  (`settingsLogic`, `playlistLogic`, `artistsLogic`, `historyLogic`, `dailyLogic`) и `wave/*`, `player/*`
  не знают ни про `window.api`, ни про `bpy`-подобные глобалы. Новую логику — туда же, с тестом.
- **Чтение `localStorage` — только через `readJson` из `src/renderer/store/json.ts`.** Прямой
  `JSON.parse(localStorage.getItem(...))` уже один раз ронял интерфейс.
- **Случайность — `cryptoRandom` и `fisherYates`** из `src/renderer/player/shuffle.ts`.
  `sort(() => Math.random() - 0.5)` не использовать: тасовка перекошенная, а `sort` ещё и меняет массив на месте.
- **Сеть всегда может молчать.** SoundCloud в России открывается только через VPN: ключ берётся один раз и
  живёт на компе, недоступный хост помечается на минуту (`SoundCloud.markDown`). Ошибки SoundCloud не должны
  тормозить поиск и Волну ВК.
- Стиль: двойных кавычек нет, точек с запятой нет, 2 пробела, строки длинные — так во всём проекте.
  Комментарии — по-русски, объясняют «почему», а не «что».

## Выпуск

Поднять `version` в `package.json` и запушить `master` → GitHub Actions соберёт установщик и выложит релиз
(`.github/workflows/release.yml`). Установленная Хвоя обновится сама через `electron-updater`.
Релиз не создаётся повторно, если тег `v<version>` уже есть.

## Чего в приложении сознательно нет

Из спецификации (`docs/superpowers/specs`, раздел «Не входит в первую версию»): тексты песен, музыка друзей,
вложения из сообщений, эквалайзер, мини-плеер поверх окон, таймер сна, Last.fm, светлая тема.
Если добавляем что-то из этого — сначала обновить спецификацию.
