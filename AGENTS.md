# Хвоя — заметки для Codex

Electron-приложение для музыки ВК и SoundCloud под Windows. Автор и единственный пользователь кода — Мориус,
общение и весь текст в интерфейсе — по-русски, на «ты».

## Команды

```bash
npm install
node dev/make-fixtures.mjs   # тестовые mp3 для режима без ВК (один раз)
npm run dev:mock             # запуск с поддельным ВК (VK_MOCK=1) — основной способ проверять правки
npm run dev                  # запуск с настоящим ВК (нужен вход)
npm test                     # vitest, 34 файла / 222 теста — запускать после каждой правки логики
npm run typecheck            # tsc по двум конфигам (node + web)
npm run lint                 # ESLint: ошибок быть не должно, предупреждения — к сведению
npm run check                # lint + typecheck + тесты одной командой
npm run dist                 # установщик локально (падает на winCodeSign — см. ниже)
```

Посмотреть правку в настоящем приложении: `npm run check` → `npm run build` →
`npx electron-builder --dir` → запустить `dist/win-unpacked/Khvoya.exe` (перед сборкой закрыть
запущенный `Khvoya.exe`, иначе `EBUSY`). Полный `npm run dist` локально спотыкается о симлинки
в кэше winCodeSign — это нормально, `--dir` всё равно кладёт готовую портативную сборку.

Переменные для `dev:mock`: `VK_MOCK_LOGIN=1` — стартовать разлогиненным, `SC_DOWN=1` — изобразить
заблокированный SoundCloud.

## Где что лежит

- `src/main/` — главный процесс. `vk/` (API ВК: `client.ts` — подпись официального приложения и повторы,
  `audio.ts` — методы `audio.*`, `models.ts`/`catalog.ts` — разбор ответов, `mock.ts`/`mockServer.ts` — подделка),
  `sc/` (SoundCloud: `soundcloud.ts` — API, ключ `client_id`, потоки; `scAuth.ts` — вход и запись через окно сайта),
  `auth/` (вход в ВК через окно сайта + `TokenKeeper`), `downloads/` (ffmpeg, теги, обложка),
  `system/` (настройки, трей, автообновление, Discord RPC), `ipc/handlers.ts` — регистрация каналов.
- `src/preload/index.ts` — мост: пропускает только каналы из `src/shared/ipc.ts`.
- `src/shared/` — то, что видят оба процесса: `types.ts`, `ipc.ts` (белый список каналов и событий),
  `match.ts` (сопоставление трека ВК ↔ SoundCloud), `updates.ts`.
- `src/renderer/` — окно. `store/` (zustand), `player/` (движок на двух `<audio>` + Web Audio, очередь,
  кроссфейд, перемешивание), `wave/` (отбор Волны: `picker.ts`, `profile.ts`, `tune.ts`), `pages/`, `ui/`,
  `theme/`.
- `src/mobile/` — Android-версия (вторая реализация тех же каналов). **Правила для неё — в
  `src/mobile/AGENTS.md`**, они дополняют этот файл, а не заменяют его.
- `docs/superpowers/specs/` — спецификация, `docs/superpowers/plans/` — план работ.

| Моё, Плейлисты, Плейлист, Загрузки, SoundCloud, Поиск | `pages/*.tsx` (имена совпадают) |
| Без вкладки: История, Похожее, Очередь, Не нравится, Настройки | `pages/History|Similar|Queue|Disliked|Settings.tsx` |

Новый экран: тип в `store/ui.ts` (`Tab`) → ветка в `pages/Pages.tsx` → если это полноценный раздел,
кнопка в `TABS` в `ui/TopBar.tsx`; если нет — пункт в меню аватара, иначе до него будет не добраться
(особенно в узком окне, где левой половины нет совсем).

## Как тут принято

- **Весь текст для человека — по-русски, на «ты», без технических кодов.** Ошибки наружу переводятся в
  понятные фразы в `src/main/ipc/handlers.ts` (`friendly()`); «Нет подключения» вместо `ENOTFOUND`.
- **Новый канал IPC = две строки в `src/shared/ipc.ts`:** подпись в `IpcMap` (какие аргументы и что
  возвращает) и имя в `IPC` (белый список моста). Дальше `handle('канал', fn)` в главном процессе и
  `window.api.invoke('канал', …)` в окне берут типы оттуда — руками тип результата писать не нужно.
  Если канал забыли в одном из двух списков, `npm run typecheck` покажет ошибку с его именем.
  Типы, которые ходят по IPC, живут в `src/shared/types.ts` (в том числе `Sc*`, `ForYouBlock`, `LocalPl`);
  главный процесс и окно их только переэкспортируют, второй раз не описывают.
- **Ключи доступа никогда не попадают в журнал.** Пишем через `log()` из `src/main/auth/webSession.ts`,
  он прогоняет текст через `redact()`. Журнал — `%APPDATA%/Хвоя/khvoya.log`.
- **Логика отделена от React и от Electron,** чтобы её можно было протестировать: `*Logic.ts`
  (`settingsLogic`, `playlistLogic`, `artistsLogic`, `historyLogic`, `dailyLogic`) и `wave/*`, `player/*`
  не знают ни про `window.api`, ни про `bpy`-подобные глобалы. Новую логику — туда же, с тестом.
- **Чтение `localStorage` — только через `readJson` из `src/renderer/store/json.ts`.** Прямой
  `JSON.parse(localStorage.getItem(...))` уже один раз ронял интерфейс.
- **Случайность — `cryptoRandom` и `fisherYates`** из `src/renderer/player/shuffle.ts`.
  `sort(() => Math.random() - 0.5)` не использовать: тасовка перекошенная, а `sort` ещё и меняет массив на месте.
- **Сеть всегда может молчать.** SoundCloud в России открывается только через VPN: ключ берётся один раз и
  живёт на компе, недоступный хост помечается на минуту (`SoundCloud.markDown`). Ошибки SoundCloud не должны
  тормозить поиск и Волну ВК.
- **Откуда играет музыка — строка `source`** (`wave:vk`, `pl:<название>`, `sc:likes`, `sc:feed`, `mine`,
  `search:<запрос>`, `artist:<имя>`, `mix:<название>`, `history`, `downloads`). Новый вид источника
  правится сразу в трёх местах: `ui/source.ts` (`sourceLabel` — подпись в шапке плеера, `sourceParts` —
  заголовок очереди) и `store/sourceNav.ts` (переход «туда, откуда играет»). Пропустишь одно —
  в плеере появится сырая строка вроде `sc:likes`.
- Стиль: двойных кавычек нет, точек с запятой нет, 2 пробела, строки длинные — так во всём проекте.
  Комментарии — по-русски, объясняют «почему», а не «что».

## Как выглядит Хвоя (держаться этого в новом)

Один язык на всё приложение: **чёрный фон, неоновый зелёный `--g` для ВК и своего, оранжевый `#FF5500`
для всего, что про SoundCloud.** Новый экран, кнопка или окно не придумывают свой вид — берут готовое.

- **Цвета — только токены из `src/renderer/theme/tokens.css`** (`--k --p1 --p2 --ln --g --text --t2 --t3 --bad`).
  Новый цвет в коде — повод сначала спросить, почему не подходит существующий. Оранжевый SoundCloud живёт
  в правилах `.sc`/`.srcb.sc`/`.wcol.sc`, а не в разметке.
- **Шрифты тоже токены:** `--H` Manrope — заголовки (800, отрицательный `letter-spacing`), `--B` Inter —
  текст и кнопки, `--M` Onest — мелкие подписи КАПСОМ, цифры и время.
- **Текст:** `--text` основной, `--t2` второстепенный, `--t3` — только для совсем фоновых подписей.
  Пустые состояния и подсказки — `--t2`: `--t3` на чёрном почти не читается.
- **Готовые кнопки, свои не рисовать:** `.btn-s` (обычная), `.btn-s.g` (главное действие), `.btn-s.bad`
  (опасное), `.ic` (иконка 38×38), `.play` (большая), `.tag` (круглый фильтр), `.seg` (переключатель),
  `.link` (мелкая зелёная ссылка КАПСОМ), `.hist` (кнопка-пилюля в шапке плеера).
- **Иконки — только SVG из `src/renderer/ui/icons.tsx`,** символами (`✕ ♥ ◆ ›`) их не заменять: у них другая
  толщина и они не попадают в сетку. Нет нужной — дорисовать в `icons.tsx` в той же манере (24×24,
  `stroke-width:2`, скруглённые концы).
- **Подсказки — обычный `title="…"`,** но рисует их не система, а `src/renderer/ui/Tooltip.tsx`
  (перехватывает `title` у элемента под курсором). Своих всплывашек не делать, системную белую не возвращать.
- **Каждое нажимаемое место отзывается:** `:hover`, `:active` и выключенное состояние обязательны;
  фокус с клавиатуры рисуется общим правилом `:focus-visible` — не отключать.
- **Радиусы и отступы из того же набора:** 8–12px у мелкого, 14–22px у карточек, шаг отступов 4px.
- **Окна поверх (`.modal`, `.menu`, `.sugg`, тосты) обязаны быть `-webkit-app-region:no-drag`.**
  Полосу перетаскивания окна Electron отдаёт системе по положению на экране, а не по слоям: без этого
  кнопки оверлея, попавшие на верхние 72px, просто не нажимаются.
- **Вся вёрстка — в `src/renderer/theme/app.css` рядом с похожим.** `style={{…}}` в разметке — только для
  того, что считается на лету (ширина полосы прогресса, цвет карточки дня).
- Заглушки, скелетоны и пустые состояния тоже часть вида: список грузится — `.skeleton`, пусто —
  `.empty-state` с человеческой фразой, что сделать.

## Что важно сохранить после последних правок Windows

- **F5 и меню профиля обновляют окно во всех разделах.** F5 обрабатывает Electron до передачи клавиши
  странице. Не занимай F5 глобальными биндами. В настройках отдельная вкладка биндов для предыдущего
  и следующего трека, паузы/продолжения, лайка и дизлайка. Бинды глобальные: работают при свёрнутом
  окне, в трее и когда фокус в другой программе. На кнопках паузы и переключения оставляй
  доступные имена для клавиатуры и скринридера без видимых подписей.
- **Скример удалён по просьбе Мориуса.** Не возвращай его, настройки или автоматический запуск
  без прямого запроса. Старое имя канала в общей схеме пока нужно для совместимости мобильного моста.
- **Временный отказ потока не означает, что трек недоступен.** Перед пропуском проверь повтор
  с обновлённой ссылкой и предусмотренный запасной источник. Это касается и ВК, и SoundCloud.
  Технические сбои не должны обучать Волну как пропуски. Сигналы считаются по фактически
  прослушанному времени, с учётом перемотки и завершения. Меняя очередь, проверь «Назад»,
  перемешивание, повтор трека и списка, восстановление очереди и переход при кроссфейде.
- **Лайк, дизлайк и подписка на артиста — разные действия.** Дизлайк исключает трек из
  будущих рекомендаций и доступен для отмены через
  список «Не нравится».
- **Артист открывается отдельной страницей** из плеера, строки и меню трека, подсказок,
  результатов поиска и карточек на главной. Передавай платформу и ID профиля, включая
  возврат из очереди. Одноимённых артистов разных сервисов не скрывай. В SoundCloud имя
  исполнителя в метаданных и имя аккаунта, загрузившего трек, могут отличаться.
- **В Windows «Мои подписки» показывает списки аккаунтов ВК и SoundCloud.** ВК читается из
  раздела «Моя музыка → Музыканты», SoundCloud — из списка аккаунта. Храним ответы только
  в памяти. Кнопки «Подписаться» и «Отписаться» меняют состояние сервиса из карточки Хвои.
  Обновляем карточку и список после подтверждения результата. Волна использует аккаунтные
  подписки, когда они загружены.
  Если профиль не найден, покажи небольшую плашку «Искать» / «Не сейчас» и открывай поиск
  по имени на нужной платформе только после «Искать».
- **Счётчик артиста показывает загруженные треки.** Для продолжения списка есть «Показать ещё».
  Блок на главной «Свежее из подписок SoundCloud» берётся из ленты сервиса.

## Проверка интерфейса Windows

- Когда Мориус просит посмотреть живую Хвою, используй встроенный Windows-скилл
  `computer-use:computer-use` из каталога `.codex/plugins/cache/openai-bundled/computer-use`.
  Если доступен `mcp__cua_repl`, используй его. Иначе штатный путь этого скилла —
  `node_repl` и `@oai/sky`. Поиск окна «Хвоя» и снимок этим способом уже работали.
- Перед выводом о правке проверь, какая версия запущена. Снимок установленной старой версии
  годится для диагностики, но не подтверждает исправление. Если проверку договорились сделать
  после установки обновления, дождись сообщения Мориуса. Правила проверки держи в `AGENTS.md`.

## Выпуск

После push выпуска всегда присылай ссылку на GitHub Actions `https://github.com/mor1us/khovoya-vk-player/actions` — там видно, как идёт сборка обновления.

Поднять `version` в `package.json` и `package-lock.json` и запушить `master` → GitHub Actions соберёт установщик и портативную
версию для Windows (`.github/workflows/release.yml`). Хвоя на компьютере обновится через
`electron-updater`. Релиз не создаётся повторно, если тег `v<version>` уже есть.
Портативную сборку отдельно Мориусу не присылай, пока он не попросит.

Последний отправленный выпуск на момент этой записи — Windows 0.4.31, коммит `47d53f3`.
Для его файлов прошли 322 теста, проверка типов и сборка. Поведение новых кнопок подписки
и плашки поиска в установленной 0.4.31 ещё надо проверить после обновления.

### Android на паузе

**Мобильную версию дорабатываем, собираем и обновляем только по прямой просьбе Мориуса.**
Запрос на правку или выпуск Хвои по умолчанию относится к Windows. Переносить функции и выпускать обе
версии одновременно пока не требуется. Ручная сборка APK доступна во вкладке Actions → «Хвоя для телефона».

### Пока версии не одинаковые

На ноябрь 2026 телефонная Хвоя умеет меньше компьютерной. Работает ВК целиком: вход, своя музыка, поиск,
плейлисты, Волна, плеер с фоном. **Не работает, хотя нарисовано: SoundCloud** — экраны и карточки Волны SC
на месте, но каналы `sc:*` и `scacc:*` отвечают «SoundCloud на телефоне пока не работает». Нет совсем:
загрузки с тегами, трей, Discord — на телефоне их и не будет.

Договорённость: сначала обкатываем ВК на телефоне, потом добавляем SoundCloud.

## Чего в приложении сознательно нет

Из спецификации (`docs/superpowers/specs`, раздел «Не входит в первую версию»): тексты песен, музыка друзей,
вложения из сообщений, эквалайзер, мини-плеер поверх окон, таймер сна, Last.fm, светлая тема.
Если добавляем что-то из этого — сначала обновить спецификацию.

## Рабочий процесс над задачами

- Перед правкой прочитай связанные файлы и коротко опиши, что нашёл.
- Меняй минимум: только то, что нужно для задачи.
- После правки запусти `npm run check` и покажи результат.
- Вход в ВК нельзя проверить без настоящего ВК. Не говори «исправлено», а напиши, что именно Мориус должен проверить руками.
- Если причина не ясна, добавь запись в журнал (log) вместо угадывания.
