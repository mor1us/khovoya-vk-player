# Хвоя

Своё приложение для музыки ВК на Windows. Без рекламы.

- Моя музыка, плейлисты (как в SoundCloud: стопки, перетаскивание, поиск и сортировка), поиск
- **Волна** — бесконечный поток, учится на ♥, пропусках и «Не то»
- Умное перемешивание (без повторов артиста подряд и без повторов до конца круга)
- Кроссфейд 0–12 с, медиаклавиши, трей, экономичный режим в играх
- Скачивание в mp3 с тегами и обложкой, слушать без интернета
- Статус «Слушает» в Discord
- **SoundCloud** рядом с ВК: общий поиск со значками ВК/SC и подсказками, вкладка SoundCloud (лайки, плейлисты, лента подписок, вход в аккаунт), ссылки на треки и плейлисты, перенос плейлиста в ВК, настоящая волна звука и комментарии по ходу трека
- Три Волны: ВК, SoundCloud и обе вперемешку; настройки по настроению, узнаваемости и языку
- Плейлисты Хвои — хранятся на компе, в них можно смешивать ВК и SoundCloud
- Запасной источник: трек не грузится — играет тот же с другого сервиса
- SoundCloud без VPN: ключ берётся один раз (с VPN) и хранится на компе
- Очередь «Сейчас играет из …», история, «Похожее», список «Не нравится» с возвратом, громкость колёсиком

## Разработка
```
npm install
node dev/make-fixtures.mjs   # тестовые треки для режима без ВК
npm run dev:mock              # запуск с поддельным ВК
npm test                      # тесты
npm run dist                  # установщик локально (на Linux нужен wine и ffmpeg.exe в node_modules/ffmpeg-static/)
```

## Выпуск обновлений
Поднять `version` в `package.json` и запушить `master` — GitHub Actions соберёт установщик под Windows и опубликует выпуск. Установленная Хвоя сама предложит обновиться.

Скачать: https://github.com/mor1us/khovoya-vk-player/releases/latest

Документы: `docs/superpowers/specs` (спецификация), `docs/first-run-check.md`, `docs/discord-setup.md`.
