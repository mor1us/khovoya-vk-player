# Хвоя

Своё приложение для музыки ВК на Windows. Без рекламы.

- Моя музыка, плейлисты (как в SoundCloud: стопки, перетаскивание, поиск и сортировка), поиск
- **Волна** — бесконечный поток, учится на ♥, пропусках и «Не то»
- Умное перемешивание (без повторов артиста подряд и без повторов до конца круга)
- Кроссфейд 0–12 с, медиаклавиши, трей, экономичный режим в играх
- Скачивание в mp3 с тегами и обложкой, слушать без интернета
- Статус «Слушает» в Discord

## Разработка
```
npm install
node dev/make-fixtures.mjs   # тестовые треки для режима без ВК
npm run dev:mock              # запуск с поддельным ВК
npm test                      # тесты
npm run dist                  # установщик для Windows (на Linux нужен wine)
```
Перед `npm run dist` на Linux положи `ffmpeg.exe` (win32-x64) в `node_modules/ffmpeg-static/`.
