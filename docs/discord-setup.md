# Как включить статус «Слушает» в Discord

Это нужно сделать один раз, займёт пару минут.

1. Открой https://discord.com/developers/applications и войди своим аккаунтом Discord.
2. Нажми **New Application**. Название — то, что друзья увидят в статусе, например **Хвоя**. Согласись с условиями и нажми **Create**.
3. На странице приложения, вкладка **General Information**, скопируй **Application ID** (длинное число).
4. Слева открой **Rich Presence → Art Assets**, нажми **Add Image(s)** и загрузи картинку `resources/icon.png` из папки приложения. Назови её ровно **logo** и нажми **Save Changes**. (Её видно, когда у трека нет обложки.)
5. В Хвое: аватарка справа сверху → **Настройки** → включи **Статус в Discord** и вставь Application ID в поле **ID приложения Discord**.
6. Discord должен быть запущен на этом же компьютере. В настройках Discord → **Конфиденциальность активности** включи «Показывать текущую активность».

Готово: пока играет трек, у тебя в профиле будет «Слушает Хвоя» с названием, исполнителем, обложкой и временем. На паузе статус пропадает.
