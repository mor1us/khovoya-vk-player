# Свой VK-плеер для Windows — спецификация

Дата: 30.10.2026
Рабочее название: **Хвоя** (можно поменять)

## 1. Цель

Своё десктопное приложение для Windows, через которое можно слушать музыку из своего аккаунта ВК. Это не копия VK Музыки и не VKM, а отдельный плеер со своим дизайном, который берёт музыку из ВК.

**Почему не VKM:** неудобный, лагает, не нравится дизайн, есть реклама.

**Успех — это когда:**
- можно войти своим аккаунтом ВК и сразу слушать свою музыку, плейлисты, рекомендации и искать треки;
- рекламы нет совсем;
- интерфейс не тормозит даже на тысячах треков;
- в свёрнутом виде (в игре) приложение почти не нагружает систему, а музыкой можно управлять медиаклавишами;
- плейлисты удобнее, чем в ВК, а изменения в них сохраняются в самом ВК.

**Для кого:** только для себя, приложение ставится на свой ПК. Публикация в магазинах не планируется.

## 2. Что входит в первую версию

| Раздел | Что умеет |
|---|---|
| Вход | Логин и пароль ВК, код 2FA, капча, автоматический вход при следующих запусках, выход |
| Моя музыка | Все свои треки, подгрузка при прокрутке, «перемешать всё» |
| Главная («Для вас») | Волна (п. 6а), рекомендации, популярное, недавно игравшее |
| Плейлисты | Сетка своих и добавленных плейлистов, страница плейлиста, создание и редактирование (см. п. 6) |
| Поиск | Строка поиска сверху (Ctrl+F), результаты: треки, артисты, плейлисты |
| Плеер | Пауза и воспроизведение, назад и вперёд, перемотка, громкость, перемешивание, повтор (выкл / весь список / один трек), очередь, кроссфейд (плавный переход между треками) |
| Скачивание | Трек или весь плейлист в mp3 с тегами и обложкой; раздел «Загрузки»; скачанное играет без интернета |
| Система | Медиаклавиши, плашка в окне громкости Windows, сворачивание в трей, экономичный фоновый режим, только одна копия приложения |
| Discord | Статус «Слушает»: трек, исполнитель, обложка, полоса времени (см. п. 10а) |
| Настройки | Папка для загрузок, закрывать в трей или выходить, анимации вкл/выкл, статус в Discord вкл/выкл, длительность кроссфейда |

**Не входит в первую версию** (можно добавить позже): тексты песен, музыка друзей, вложения из сообщений, эквалайзер и выравнивание громкости, мини-плеер поверх окон, таймер сна, Last.fm, светлая тема, автообновление.

## 3. Технологии

- **Electron** + **TypeScript**.
- Интерфейс на **React** + **Vite**, состояние хранится в **Zustand**.
- Длинные списки рисуются частями (**@tanstack/react-virtual**).
- Зашифрованный поток ВК (HLS, AES-128) играет через **hls.js**, обычные mp3-ссылки — через `<audio>` напрямую.
- Скачивание через **ffmpeg** (готовая сборка `ffmpeg-static` внутри приложения): поток превращается в mp3, ему пишутся теги и обложка.
- Медиаклавиши и плашка Windows работают через **Media Session API** браузерного движка Chromium внутри Electron.
- Сборка установщика для Windows: **electron-builder**.

## 4. Устройство

```
┌──────────────── Главный процесс («мотор») ────────────────┐
│ auth/      вход, 2FA, капча, хранение ключа (safeStorage)  │
│ vk/        клиент VK API: запросы, ошибки, повтор попыток  │
│ downloads/ очередь скачивания, ffmpeg, теги, индекс файлов │
│ system/    трей, окно, фоновый режим, настройки, Discord   │
│ ipc/       мост: список разрешённых команд для окна        │
└───────────────────────────┬────────────────────────────────┘
                            │ IPC (только через preload)
┌───────────────────────────┴──── Окно («лицо») ─────────────┐
│ player/    очередь, перемешивание, повтор, hls.js, Media   │
│            Session, запоминание позиции                    │
│ pages/     Моя музыка, Для вас, Плейлисты, Плейлист,       │
│            Поиск, Загрузки, Настройки, Вход, сцена       │
│ ui/        общие компоненты: строка трека, карточка        │
│            плейлиста, панель плеера, меню                  │
│ theme/     палитра, шрифты, режим «без анимаций»           │
└────────────────────────────────────────────────────────────┘
```

Правила:
- Окно работает в изоляции (`contextIsolation`, без Node.js) и не знает ключа доступа. Обращаться к ВК оно может только через мост и только командами из разрешённого списка.
- Каждый модуль решает одну задачу. `vk/` ничего не знает об интерфейсе, `player/` ничего не знает о ВК: он получает готовые треки с ссылками.

## 5. Вход в ВК

- Используется тот же способ, что у VKM и подобных клиентов: прямой вход по логину и паролю от имени приложения Kate Mobile, с его публичными `client_id`/`client_secret` и его User-Agent. Только такие ключи дают доступ к методам `audio.*`.
- Пароль отправляется только на `oauth.vk.com` и нигде не сохраняется.
- Ответ `need_validation` → показываем поле для кода (SMS или приложение), повторяем вход с кодом.
- Ответ `need_captcha` → показываем картинку и поле, повторяем вход с ответом. Картинку капчи загружает главный процесс и передаёт в окно готовой (data URL), чтобы она точно показалась: у других клиентов капча часто не грузится. Рядом есть кнопка «Другая картинка».
- Полученный ключ шифруется через Electron `safeStorage` (защита данных Windows) и хранится в файле настроек.
- Если ВК отзовёт ключ (ошибка 5), появится экран входа с сообщением «Сессия ВК закончилась, войди снова».
- Выход: удалить ключ и вернуться на экран входа.

**Риск:** это неофициальный способ. ВК может его поменять или сломать. Поэтому вся работа с ВК собрана в `vk/` и `auth/`, чтобы при поломке чинить только там.

## 6. Плейлисты (как в SoundCloud)

- **Сетка:** крупные квадратные обложки, при наведении появляется кнопка ▶ (включает плейлист без перехода на его страницу). Сверху переключатель «Мои / Добавленные».
- **Страница плейлиста:** слева большая обложка, рядом название, автор, число треков, длительность и кнопки «Играть», «Перемешать», «Скачать всё», «Изменить». Ниже список треков.
- **Удобства:**
  - треки перетаскиваются мышкой внутри плейлиста (`audio.reorder`);
  - трек можно перетащить на стопку плейлиста или выбрать «Добавить в плейлист» в меню трека;
  - можно выделить несколько треков (Ctrl/Shift + клик) и добавить их в плейлист одной командой;
  - внутри плейлиста есть поиск и сортировка (по дате добавления, названию, артисту). Сортировка не меняет порядок в ВК;
  - при добавлении трека, который уже есть в плейлисте, появится предупреждение «Уже есть в плейлисте»;
  - кнопка «Сохранить очередь как плейлист».
- Все изменения уходят в ВК (`audio.createPlaylist`, `audio.editPlaylist`, `audio.addToPlaylist`, `audio.removeFromPlaylist`, `audio.deletePlaylist`). Интерфейс обновляется сразу, а если ВК вернёт ошибку, изменение откатывается и показывается сообщение.

## 6а. Волна (своя «Моя волна»)

Бесконечный поток музыки, который подстраивается под реакции. VK Микс сторонним приложениям, скорее всего, недоступен, поэтому Волна своя, поверх рекомендаций ВК и локального профиля вкуса.

- **Где:** большая карточка «Волна» в начале главной страницы, кнопка ▶ запускает поток.
- **Режимы:**
  - «Микс» (по умолчанию) — примерно 70% нового и 30% твоего;
  - «Новое» — только то, чего нет в твоей музыке;
  - «Любимое» — твои треки в умном порядке.
- **Откуда берутся треки:**
  - `audio.getRecommendations` с `target_audio` (похожие на конкретный трек) — от 3–5 «зёрен»;
  - общие рекомендации (`audio.getRecommendations` без цели);
  - твоя музыка.
  - Зёрна — недавно лайкнутые и дослушанные треки, с упором на свежие.
- **Обучение** (всё хранится локально в `wave-profile.json`):
  - ♥ лайк / добавить к себе: артист +3, трек становится зерном;
  - дослушал до конца: артист +1;
  - пропуск в первые 30 секунд: артист −1, трек больше не предлагается неделю;
  - кнопка «Не то» (👎): трек больше не предлагается никогда, артист −5, следующий трек включается сразу.
- **Отбор следующей пачки (по 20 треков):**
  - убираются дизлайки, недавно звучавшее (последние 300) и артисты с весом ниже −6;
  - остальное ранжируется по весу артиста плюс небольшая случайность, чтобы поток не застывал;
  - не больше 2 треков одного артиста на пачку.
- Пачка подгружается, когда в очереди Волны остаётся 5 треков. Поток бесконечный.
- **Честно:** это не нейросеть уровня Яндекса. Подстраивается он за счёт твоих реакций, и чем больше ты лайкаешь и пропускаешь, тем точнее поток. Если `audio.getRecommendations` с ключом Kate окажется недоступен, Волна строится из «похожих артистов» через поиск и из твоей музыки. Это проверяем на первом шаге вместе со входом.

## 7. Плеер

- Очередь создаётся из места, откуда запущен трек (свои треки, плейлист, поиск, рекомендации).
- **Умное перемешивание.** Обычное «случайно» людям кажется неслучайным: один артист идёт подряд, одни и те же треки всплывают каждый раз. Поэтому:
  1. Основа — честная перетасовка Фишера — Йетса на криптографическом генераторе (`crypto.getRandomValues`), а не `Math.random` и не сортировка по случайному ключу.
  2. **Разнесение артистов:** треки одного исполнителя равномерно распределяются по всей очереди (со случайным сдвигом), поэтому два трека одного артиста подряд почти не выпадают.
  3. **Без повторов до конца круга:** пока не прозвучали все треки списка, ни один не повторится.
  4. **Память между запусками:** последние ~200 прослушанных треков запоминаются, и новое перемешивание отправляет их в конец очереди. Начало не будет каждый раз одинаковым.
  - Текущий трек остаётся первым. При выключении перемешивания восстанавливается исходный порядок.
- Повтор: выкл → весь список → один трек.
- Когда до конца трека остаётся около 10 секунд плюс длительность кроссфейда, заранее загружается следующий трек.
- **Кроссфейд:**
  - в плеере два аудиоэлемента, каждый подключён к своему `GainNode` (Web Audio);
  - за N секунд до конца трека запускается следующий, громкость одного плавно уходит вниз, другого поднимается (кривая равной мощности, чтобы в середине не было провала);
  - N настраивается от 0 (выкл) до 12 секунд, по умолчанию 3;
  - при ручном переключении («вперёд», «назад», клик по треку) переход короткий, 0,3 секунды, без щелчка;
  - при повторе одного трека и для треков короче 30 секунд кроссфейд не используется;
  - в фоновом режиме кроссфейд работает как обычно: это только звук, интерфейс не нужен.
- Ссылки ВК со временем протухают. Если ссылка не играет, приложение один раз запрашивает её заново (`audio.getById`), а если снова не вышло, пропускает трек и показывает уведомление.
- Если трек скачан, он играет из файла.
- Позиция, очередь и громкость сохраняются, при запуске плеер продолжает с того же места (но на паузе).
- Поиск ищет ровно то, что введено. Подсказки (история запросов) появляются только под строкой и не мешают нажать Enter.
- Клавиши: пробел — пауза, ←/→ — перемотка ±5 с, ↑/↓ — громкость, Ctrl+F — поиск.

## 8. Скачивание

- Кнопка на треке, «Скачать всё» на плейлисте.
- Скачивается последовательно, по 2 трека одновременно. Прогресс виден в разделе «Загрузки».
- ffmpeg получает ссылку ВК и делает mp3 320 кбит/с (если исходник mp3 — просто копирует), записывает теги «Исполнитель» и «Название» и вшивает обложку.
- Имя файла: `Исполнитель - Название.mp3`, запрещённые в Windows символы заменяются.
- Список скачанного хранится в `downloads.json` (id трека → путь). Если файл удалили вручную, трек просто снова считается нескачанным.

## 9. Дизайн

Основа — макет `design/concept-e-flat.html` (вариант E).

- **Палитра** (плоская, без градиентов, свечений и размытий):
  - фон Deep Black `#0B0B0B`;
  - панели `#141414`, выделенная строка `#1B1B1B`, линии `#262626`;
  - акцент Neon Green `#39FF14`, текст на нём `#0B0B0B`;
  - текст `#F5F5F5`, вторичный `#A8A8A8`, третичный `#5C5C5C`.
- **Шрифты:** Manrope (заголовки), Inter (текст), Onest (мелкие подписи: время, счётчики, «ИГРАЕТ ИЗ»). Шрифты лежат внутри приложения и не грузятся из интернета.
- **Раскладка:**
  - **Сцена слева** (≈43% ширины) — текущий трек: большая обложка, крупное название, исполнитель, плашки (год, битрейт), источник («ИГРАЕТ ИЗ · ВОЛНА / МИКС»), полоса перемотки в виде звуковой волны, подпись кроссфейда, кнопки ♥ «В мою» / 👎 «Не то», назад / пауза / вперёд, перемешивание и повтор, а также громкость и очередь.
  - **Справа сверху** — разделы крупным текстом: Главная · Моё · Плейлисты · Загрузки, поиск (Ctrl+F), аватар с меню (Настройки, Выйти), кнопки окна (рамка окна своя).
  - **Справа** — содержимое раздела.
- **Главная:** сверху «Ящики с плейлистами» (стопки обложек), снизу два блока: зелёная карточка **Волна** (чёрный текст, режимы, чёрная кнопка ▶, движущиеся чёрные линии) и **«Похоже на это»** с подписью, почему трек попал в список.
- **Узкое окно** (уже 1100 px): сцена превращается в панель плеера внизу, содержимое занимает всю ширину.
- **Обложки** — настоящие обложки треков. Без обложки показывается плоская заглушка из фигур в двух цветах палитры.
- **Анимации:** короткие (150–250 мс), только движение и прозрачность. Линии Волны двигаются, пока окно на экране.
- **Рекламы нет нигде.**

## 10. Экономичный фоновый режим

Когда окно свёрнуто или спрятано в трей:
- окну отправляется событие `app:background`, интерфейс включает класс `paused-ui`: все CSS-анимации, размытия и переходы выключаются, таймеры интерфейса останавливаются;
- не загружаются обложки и рекомендации, не обновляется полоса перемотки;
- работают только звук, Media Session и уже начатые скачивания;
- окно ничего не перерисовывает (Chromium не рисует скрытое окно).

**Цель:** не больше ~1–2% процессора и около 0% видеокарты во время воспроизведения в фоне (проверяется по диспетчеру задач).

Закрытие крестиком по умолчанию прячет окно в трей. В меню трея: «Показать», «Пауза», «Следующий», «Выход».

Одна копия: при повторном запуске (ярлык, второй клик) новая копия не открывается, а показывается уже работающее окно (`app.requestSingleInstanceLock`).

## 10а. Статус в Discord

- Модуль `system/discord` в главном процессе подключается к Discord на этом же ПК через локальный канал (библиотека `@xhayper/discord-rpc`). Интернет для этого не нужен, ключ ВК в Discord не передаётся.
- Статус «Слушает <название приложения>»:
  - первая строка — название трека;
  - вторая строка — исполнитель;
  - большая картинка — обложка трека (по ссылке), а без обложки — значок приложения;
  - полоса времени (начало и конец трека).
- На паузе статус убирается. При смене трека, паузе или перемотке он обновляется одним сообщением, без постоянного опроса, поэтому в фоне нагрузки почти нет.
- Если Discord не запущен, приложение молча пробует подключиться раз в 30 секунд и не показывает ошибок.
- В настройках есть переключатель «Показывать статус в Discord», по умолчанию он включён.
- Нужен ID приложения из Discord Developer Portal. Его создаёшь ты, один раз, по пошаговой инструкции: там же задаются название и значок, которые увидят друзья. ID вписывается в настройки.

## 11. Ошибки

- Нет интернета: плашка «Нет подключения», скачанные треки продолжают играть.
- Ошибка ВК 6 (слишком много запросов): пауза и повтор запроса, до 3 попыток.
- Ошибка ВК 5 (ключ недействителен): экран входа.
- Ошибка 14 (капча) при обычных запросах: окно с капчей, после ответа запрос повторяется.
- Трек недоступен (изъят правообладателем): строка серая, при воспроизведении трек пропускается.
- Все сообщения короткие и понятные, без технических кодов.

## 12. Проверка

- **Автотесты (Vitest)** для логики без ВК:
  - очередь, перемешивание (равномерность Фишера — Йетса на 100 000 прогонов, разнесение артистов, отсутствие повторов внутри круга), повтор;
  - кроссфейд (расчёт кривых громкости и моментов старта);
  - Волна: обновление весов от реакций, фильтры, ранжирование, лимит артиста в пачке;
  - разбор ответов ВК в модели треков и плейлистов;
  - сценарии входа (2FA, капча) на поддельных ответах;
  - имена файлов и индекс загрузок;
  - откат изменений плейлистов при ошибке.
- **Поддельный ВК (mock)** для запуска интерфейса без реального аккаунта: разработка и скриншоты делаются на нём.
- **Проверка на реальном ВК** проходит на твоём ПК: из облачной среды разработки ВК недоступен. Первым шагом после сборки проверяем вход и воспроизведение (самая рискованная часть).
- **Проверка нагрузки:** свернуть приложение во время игры, посмотреть процессор и видеокарту в диспетчере задач.
