# Хвоя (свой VK-плеер) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows-приложение «Хвоя»: слушать, искать, скачивать музыку из своего аккаунта ВК без рекламы, с Волной, умным перемешиванием, кроссфейдом и статусом в Discord.

**Architecture:** Electron, три части (electron-vite): главный процесс (ВК, вход, загрузки, трей, Discord), preload-мост с белым списком команд, окно на React (плеер, страницы). Вся логика без ВК — чистые функции с тестами; ВК подменяется поддельным бэкендом (`VK_MOCK=1`) для разработки в облаке.

**Tech Stack:** Electron 33+, electron-vite, TypeScript (strict), React 18, Zustand, @tanstack/react-virtual, hls.js, ffmpeg-static, @xhayper/discord-rpc, Vitest, electron-builder.

**Spec:** `docs/superpowers/specs/2026-10-30-vk-player-design.md`; дизайн-эталон `design/concept-e-flat.html`.

## Global Constraints

- Палитра только плоская: `#0B0B0B` фон, `#141414` панели, `#1B1B1B` выделение, `#262626` линии, акцент `#39FF14`, текст `#F5F5F5` / `#A8A8A8` / `#5C5C5C`. Никаких градиентов, свечений, `backdrop-filter`.
- Шрифты Manrope / Inter / JetBrains Mono — локальные файлы в `src/renderer/assets/fonts`, без сетевых загрузок.
- Окно: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`; токен ВК никогда не уходит в renderer.
- Kate Mobile: `client_id=2685278`, `client_secret=lxhD8OD7dMsqtXIm5IUY`, User-Agent `KateMobileAndroid/56 lite-460 (Android 4.4.2; SDK 19; x86; unknown Android SDK built for x86; en)`, API `v=5.131`.
- Весь интерфейс на русском; сообщения об ошибках без кодов.
- Рекламы нет нигде.
- Фоновый режим: при скрытом окне — ни одной анимации, таймера UI или сетевого запроса кроме звука, загрузок и Discord.

## Review Focus

- Трек без ссылки (`url: ""`, изъят правообладателем) — строка серая, плеер пропускает его, не падает (тест в Task 6 и Task 7).
- Огромная библиотека (5000+ треков) — `audio.get` листается пачками по 1000, список виртуальный (тест пагинации в Task 5).
- Ключ отозван (ошибка 5) посреди прослушивания — показывается вход, очередь и позиция сохраняются (тест в Task 3 + сохранение состояния Task 8).
- Имена файлов с `\/:*?"<>|`, зарезервированными именами (`CON`, `NUL`), точкой в конце и длиной >150 символов (тест в Task 13).
- Протухшая ссылка / обрыв сети посреди трека — один перезапрос `audio.getById`, затем пропуск с уведомлением (тест в Task 7).

### Task 6: Очередь, умное перемешивание, повтор

**Files:** Create `src/renderer/player/queue.ts`, `src/renderer/player/shuffle.ts`; Test `tests/queue.test.ts`, `tests/shuffle.test.ts`

**Interfaces — Produces:** `smartShuffle(tracks:Track[], opts:{firstId?:string; recent:string[]; rnd?:()=>number}):Track[]`; `class Queue { constructor(tracks:Track[], startIndex:number, source:string); current():Track|null; next(auto:boolean):Track|null; prev():Track|null; peekNext():Track|null; setShuffle(on:boolean, recent:string[]):void; repeat:'off'|'all'|'one'; jumpTo(id:string):void; toJSON(); static fromJSON() }`. `rnd` по умолчанию на `crypto.getRandomValues`.

Алгоритм `smartShuffle`: (1) Фишер — Йетс; (2) группировать по артисту, каждую группу размером k разложить на позиции `floor((i + u)·n/k)` со случайным сдвигом `u∈[0,1)` и уникализацией коллизий сдвигом вправо; (3) треки из `recent` (последние 200) переставить в конец, сохраняя порядок; (4) `firstId` на позицию 0.

- [ ] Step 1: тесты:
  - 100 000 перетасовок 4 элементов: частота каждого элемента на каждой позиции в пределах ±2% от 25%;
  - 50 треков, 10 артистов по 5: ни разу два одинаковых артиста подряд в 1000 прогонах ≥ 95% случаев, и в среднем < 1 соседства;
  - `recent` треки оказываются в последних позициях; `firstId` первый;
  - Queue: при `repeat:'all'` после последнего — первый; `'one'` + `next(true)` возвращает тот же, `next(false)` — следующий; выключение shuffle возвращает исходный порядок с тем же текущим; `next` пропускает `available:false`; все недоступны → `null`.
- [ ] Step 2: реализовать. PASS. Commit.
